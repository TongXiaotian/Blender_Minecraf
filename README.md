# Blender Minecraft（我的世界 · Blender 版）

用 **Blender 的 Python API（含 GPU 绘制）** 写的类《我的世界》体素沙盒游戏：
程序化地形、挖掘/放置、第一人称物理、贴图图集、以及一套照原版做的 HUD / 物品栏界面。

> 测试环境：**Blender 5.2.2 LTS**（Python 3.13 / numpy 2.3.4）。
> 已验证：逻辑测试、方向一致性测试、GUI 端到端测试（真实事件驱动 + 截图）、Cycles 预览渲染。

---

## 1. 安装与启动

**方式 A：装成插件（推荐）**

1. Blender → `编辑` → `偏好设置` → `插件` → 右上角 `安装…`（Install from Disk）
2. 选择本目录下的 **`blender_minecraft.zip`**（或直接选 `blender_minecraft/__init__.py`）
3. 勾选启用 “**Blender Minecraft (我的世界)**”
4. 把鼠标放到 3D 视图里 → 按 **`N`** 打开右侧栏 → 选 **`Minecraft`** 标签 → 点 **开始游戏**
   （或者在 3D 视图里按 **`Shift+M`**，或菜单 `视图(View)` → `开始我的世界`）

**方式 B：不用安装，直接跑**

1. Blender → 顶部 `Scripting` 工作区 → `打开` → 选 `blender_minecraft/__init__.py`
2. 点 ▶️ 运行（或 `Alt+P`），然后按上面的第 4 步开始游戏

> 建议先把 3D 视图**最大化**（鼠标放视图里按 `Ctrl+空格`）再开始，视野更大。

侧栏里可以设置：**世界种子**（0 = 随机）、**渲染距离**（2–12 区块）、**画质**、**创造/生存**。

## 3. 做了什么（对照原版）

**已实现**

* **世界生成**：值噪声 fBm 高度场 + 山脉、海洋（海平面 y=62）、沙滩、雪原/沙漠生物群系、
  3D 噪声洞穴、煤/铁/金/钻石矿脉（按深度分布）、橡树（树木密度随湿度变化）、基岩层、寒冷群系水面结冰。
* **区块系统**：16×16×128 区块、按需生成、渲染距离内自动生成/建网格、远处卸载。
* **网格**：向量化提取可见面（被挡住的面直接剔除）、**逐顶点 AO（环境光遮蔽）**、
  顶/侧/底面固定明暗，全部烘焙进顶点色，所以不需要光照贴图也有立体感。
  实测：约 **9.7 ms / 区块**（中位 3.7 ms）。
* **贴图**：**零外部素材**，36 种方块贴图 + 心形/饥饿/裂纹等 HUD 贴图全部用 numpy 现场画出
  （`mc_textures.py`），打包成一张 256×256 图集，`Closest` 采样保持像素风。
* **玩法**：DDA 体素射线锁定方块（4.5 格内）、创造模式瞬间破坏 / 生存模式按硬度计时破坏
  （带裂纹叠加显示）、放置、中键取方块、36 格背包（9 快捷栏 + 27 背包，可拖拽/右键分半）、
  创造模式物品栏（35 种方块），摔落伤害、溺水、缓慢回血、死亡与重生。
* **物理**：AABB 逐轴碰撞、重力 32 m/s²、跳跃约 1.25 格、行走 4.32 / 疾跑 5.61 m/s、
  游泳、飞行、潜行防坠落、走路视角摆动、疾跑 FOV 变化。
* **界面（全部 GPU 手绘）**：准星、快捷栏（**等距 3D 方块图标** + 数量）、选中框、
  生命/饥饿/经验条、水下气泡、物品名弹窗、聊天框与消息淡出、
  F3 调试面板、创造/生存物品栏（悬浮高亮 + 原版风格的紫色边框提示框）、
  暂停菜单、死亡界面、载入进度界面、方块选中黑色描边、昼夜天空色与太阳亮度。
* **昼夜**：20 分钟一个完整昼夜，天空颜色插值、太阳高度与亮度变化。
* **其它**：中文界面（自动加载系统中文字体，找不到则回退）、中文聊天、简单粒子…（无）。

**没做（与原版的差距，别期待）**

* 没有生物/怪物（僵尸、苦力怕…），没有战斗与生命值来源。
* 没有合成/熔炼/附魔/红石，没有岩浆/下界/末地。
* 没有流体流动（水不会蔓延）、没有光照传播（洞窟里和地面一样亮，只有 AO）。
* 没有音效与背景音乐（Blender 里做实时音频不现实）。
* 没有物品掉落物实体（生存模式挖到的东西直接进背包）。
* 只有整数倍分辨率的 HUD 缩放，没有原版全部设置项。

## 4. 性能说明（重要）

Blender 是渲染器不是游戏引擎，这个项目的性能瓶颈在视口渲染，不在 Python 逻辑。

实测（Intel 核显，视口 1574×869，MATERIAL 预览 + 阴影）：

| 阶段 | 表现 |
| --- | --- |
| 生成世界 + 建网格 | 约 9.7 ms/区块（中位 3.7 ms），纯 Python/numpy |
| **首次进入的"暖机"** | **10~25 秒**：Blender 第一次真正绘制这个场景要编译着色器 / 上传 GPU 数据，期间视口是空的。游戏会一直显示"正在准备渲染…"进度界面等它完成，不会把空画面露给你 |
| 暖机完成后的稳定状态 | **60 FPS**（16 ms/帧），即使已加载 100 个区块 |
| 玩家移动、新区块建网格时 | 掉到 **8~15 FPS**，因为每新建一个网格对象 Blender 都要重新同步一次 |

两个关键修复（都在代码里）：

* `scene.eevee.taa_samples`：视口默认 16，而本游戏每帧都在改场景，
  EEVEE 就真的每帧渲染 16 遍采样 → **单帧 3 秒**。游戏启动时设成 1（画质=高 时 4），退出还原。
* 每帧写 Blender 属性（相机 FOV、天空色、太阳朝向、每个区块的 `hide_viewport`）
  都会让整个场景重新求值。现在全部改成"变了才写"，并把"隐藏远处区块"改成只在
  玩家跨区块时做一次。

想更流畅：`画质` 设为 **低**（关阴影），或把 `渲染距离` 调到 3–4。
暖机时间与 GPU 驱动有关，独显上通常几秒。

上面的数字都能用 `tools/` 里的脚本复现（见下）。

## 5. 文件结构

```
blender_minecraft/
├── __init__.py        插件入口：侧栏面板、菜单、快捷键、注册
├── mc_const.py        常量（区块尺寸、世界高度、物理参数、面朝向）
├── mc_blocks.py       方块注册表（36 种：贴图、硬度、掉落、是否固体/透明）
├── mc_textures.py     程序化像素贴图（numpy 画图，产出 256×256 图集）
├── mc_world.py        世界与区块、噪声、生物群系、洞穴、矿脉、树木
├── mc_mesher.py       向量化网格生成（面剔除 + AO + 顶点色）——纯 numpy
├── mc_render.py       Blender 侧：图集图像、材质、区块对象、光照、相机
├── mc_raycast.py      DDA 体素射线、视线方向、方向→Blender 坐标换算
├── mc_player.py       玩家物理：碰撞、跳跃、游泳、飞行、伤害
├── mc_inventory.py    背包 / 快捷栏 / 创造模式物品栏逻辑
├── mc_ui.py           HUD 与全部界面绘制（gpu + blf，立即模式）
├── mc_game.py         游戏主循环：模态操作符、输入、区块流式加载、聊天指令
└── mc_save.py         存档 / 读档（.npz）
```

**坐标系约定**（改代码时务必注意）：
游戏内部一律用 **Minecraft 约定 `(x, y, z)`，其中 `y` 是高度**；
只有在交给 Blender 的相机位置、绘制回调时，才用 `mc_raycast.to_blender()` 换成
Blender 的 `(X, Y, Z=向上)`。混用会导致“准星指着的方块和实际打到的方块不是一个”。

## 6. 测试脚本（`tools/`，都需要用 Blender 跑）

| 脚本 | 作用 |
| --- | --- |
| `logic_test.py` | 无界面逻辑测试：图集/地形/网格/射线/物理/背包/存档/UI 布局，40+ 项 |
| `test_aim.py` | 视线与移动方向一致性（防止坐标系写反） |
| `install_test.py` | 把 zip 当插件安装/启用/禁用，验证注册流程 |
| `gui_test.py` | **端到端**：真实事件驱动（`--enable-event-simulate`）开一局，挖掘/放置/取方块/开界面，截图 + 写诊断 json |
| `panel_test.py` | 用户主路径：启用的插件 + 侧栏按钮启动游戏 + 截图 + 退出后视图状态还原检查 |
| `shot_clean.py` | 干净的首屏截图（不做任何会打断渲染的操作） |
| `preview_render.py` | 后台生成地形并用 Cycles 渲染一张高清预览图 |
| `bench_mesh.py` | 地形/网格生成性能基准 |
| `exit_test.py` | 退出路径：确认对象清理干净、视口状态还原、Blender 存活 |
| `perf_test.py` / `probe_loop.py` / `probe_render.py` | 性能对照实验（定位渲染/逻辑瓶颈用） |

运行示例（把 `BLENDER` 换成你的 blender.exe 路径）：

```powershell
# 逻辑测试
& $BLENDER --background --factory-startup --python tools/logic_test.py
# 方向一致性
& $BLENDER --background --factory-startup --python tools/test_aim.py
# 端到端（会弹出一个 Blender 窗口，自动玩 30 秒后自己退出）
& $BLENDER --enable-event-simulate --factory-startup --python tools/gui_test.py -- 30
# 预览渲染（生成预览图并导出贴图图集）
& $BLENDER --background --factory-startup --python tools/preview_render.py -- 5 preview.png
```

## 7. 二次开发提示

* **加方块**：在 `mc_textures.py` 的 `TILE_NAMES`/`_BUILDERS` 里加贴图，
  再到 `mc_blocks.py` 里 `_add(...)` 注册即可（六面贴图、硬度、掉落都在那）。
* **调地形**：`mc_world.World.generate()` 里的高度/群系公式，
  可用 `tools/tune.py` 类似的方式（见 git 历史）先看统计再定阈值。
* **加界面**：`mc_ui.py` 里 `rect()/icon()/text()/block_icon()` 是全部原语，
  绘制分三趟（纯色 → 贴图 → 文字），布局函数（如 `inventory_layout`）绘制与点击共用。
* **加指令**：`mc_game._run_command()`。
